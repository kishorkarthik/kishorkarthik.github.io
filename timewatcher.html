TimeWatcher

Keep your hands on the keyboard—log your active work hours via the CLI.

TimeWatcher is a CLI-first time tracking application built for developers. It helps you track focused work sessions without leaving the terminal, making time tracking a natural part of your development workflow.

TimeWatcher helps you understand your work patterns, reflect on progress, and make better decisions about where your time goes.

Features
  • Start and stop work sessions
  • View active session status
  • Review completed session history
  • Local SQLite persistence
  • Repository-based architecture
Installation

Clone the repository:

                  
    git clone https://github.com/kishorkarthik/timewatcher.git
    cd timewatcher

Install dependencies:

                
    uv sync

Run timewatcher:

                
    uv run timewatcher --help
Current Commands

Start a session

                
    timewatcher start "example: let's get started."

Check active session

                
    timewatcher status

Stop curret session

                
    timewatcher stop

View completed sessions

                
    timewatcher history
